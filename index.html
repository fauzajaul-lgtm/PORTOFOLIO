Aplikasi di PT Blue Rose Narado

Empat aplikasi yang saya kerjakan sejak Juni 2026. Semuanya dibangun dengan Next.js, Node.js dan Supabase (PostgreSQL), lalu dijalankan dengan Docker Compose di VPS.

SIMS

Smart Integrated Manufacturing System

Sistem ERP pabrik yang menyatukan alur sales, pembelian, gudang, cutting, produksi sampai QC dalam satu aplikasi.

Dipakai oleh
Semua departemen
Peran saya
Membangun dari awal
  • Modul Sales, Purchase, gudang bahan baku dan barang jadi, Cutting, Production, dan QC/QA.
  • Dashboard ringkas untuk sales order aktif, PO yang masih terbuka, dan antrean produksi.
  • Bisa dipakai untuk lebih dari satu pabrik, dengan opsi masuk sambil scan karton untuk alur kerja gudang.

CostingBOM

Pengecekan BOM dan perhitungan costing

Aplikasi untuk mengecek Bill of Material (BOM) tiap style dan menghitung costing-nya sebelum order diproduksi.

Dipakai oleh
Departemen Merchandise
Peran saya
Membangun dari awal
  • Membandingkan BOM baru dengan BOM lama per brand supaya perbedaan material langsung terlihat.
  • Menandai baris MML yang masih perlu dikonfirmasi sebelum costing dibuat.
  • Memantau umur data MML tiap brand, jadi tim tahu kapan data perlu diunggah ulang.

MD Production

Pengolahan order list produksi

Aplikasi untuk mengolah order list dari Merchandise sampai siap dirilis ke SIMS, termasuk penentuan ukuran packing.

Dipakai oleh
Departemen Merchandise dan Warehouse
Peran saya
Membangun dari awal
  • Menghitung ukuran packing secara otomatis berdasarkan region tujuan. Fitur ini dipakai tim Warehouse.
  • Mengolah order list, DOL dan PLN per brand, lalu merilisnya ke SIMS.
  • Daftar pekerjaan yang perlu ditindaklanjuti, diurutkan dari yang paling mendesak, plus pengecekan kelengkapan data master.

Production Tracker

Pemantauan output tiap line produksi

Dashboard output, OK dan reject untuk setiap line produksi di pabrik Cianjur.

Dipakai oleh
Tim produksi pabrik Cianjur
Peran saya
Melanjutkan pengembangan
  • Melanjutkan pengembangan aplikasi yang sudah berjalan dengan menambah dan menyempurnakan fitur.
  • Setiap line masuk dengan akunnya sendiri, sedangkan dashboard dibuka dengan PIN.
  • Tersedia report, progress PO, riwayat, KPI, laporan defect, dan rekap terpisah untuk trolley pasang roda.

Analisis sistem dan GIS

Sebelum di PT Blue Rose Narado, pekerjaan saya ada di dua bidang. Sebagai system analyst, saya menggali kebutuhan user lalu menuangkannya ke SRS, ERD dan mockup. Sebagai GIS analyst, saya mengolah data spasial menjadi peta.

LRS Admin Dashboard

PT Len Railway Systems, analisis sistem

Panel admin untuk mengelola isi website perusahaan dalam dua bahasa: berita, artikel, galeri, banner dan lowongan kerja. Saya menyusun SRS, DFD dan spesifikasi API, merancang ERD termasuk role, hak akses dan log aktivitas, lalu membuat mockup di Figma sebagai acuan developer.

Figma, Draw.io, PostgreSQL

SiJagung

Sistem Informasi Jagung Nasional, GIS dan analisis sistem

Aplikasi pemantauan produksi jagung per wilayah. Di sisi GIS, saya mengolah data spasial di QGIS, ArcGIS dan Google Earth Engine menjadi GeoJSON untuk peta sebaran. Di sisi analisis, saya menggali kebutuhan kelompok tani dan mendesain form laporannya di Figma.

QGIS, ArcGIS, Google Earth Engine, Figma

Manajemen Aset IT

Aplikasi internal perusahaan, analisis sistem

SRS dan rancangan proses bisnis To-Be untuk pengelolaan aset IT: data master, siklus hidup aset, audit berkala, sampai pelaporan.

Visio, Figma, SRS
